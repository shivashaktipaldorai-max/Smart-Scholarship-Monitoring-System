# Smart Scholarship Monitoring System

## 📌 Project Description

The Smart Scholarship Monitoring System is a web-based application designed to monitor and manage scholarship applications efficiently. It provides a centralized dashboard to track scholarship applications and uses a Machine Learning model to predict the potential delay risk of scholarship applications.

The system categorizes applications based on their predicted risk and displays the prediction confidence, helping users identify applications that may require attention.

## 🚀 Key Features

- Scholarship application monitoring
- Centralized dashboard
- Machine Learning-based delay risk prediction
- High Delay Risk identification
- Low Delay Risk identification
- Prediction confidence percentage
- Application status tracking
- User-friendly interface
- Data visualization and monitoring

## Installation Steps

1. Clone the repository.

2. Open the project folder in Terminal.

3. Install the required dependencies:

pip install -r requirements.txt

## Execution Steps

1. Run the application:

python app.py

2. Open your web browser.

3. Go to:

http://127.0.0.1:5000

## Machine Learning Prediction

The system uses a Machine Learning model to predict the potential delay risk of scholarship applications.

The prediction results are displayed as:

- High Delay Risk – Needs Attention
- Low Delay Risk – No Immediate Attention Needed

The system also displays the prediction confidence percentage.

## Project Objective

The main objective of this project is to provide an efficient and intelligent system for monitoring scholarship applications and identifying applications that may require attention due to potential processing delays.
